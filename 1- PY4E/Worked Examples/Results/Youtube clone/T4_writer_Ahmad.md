# How to Open and Interact with the Single-File YouTube Clone

This guide provides simple instructions on how to save, open, and interact with the single-file YouTube clone web application in any modern web browser.

---

### Prerequisites
You will need:
* A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, or Apple Safari).
* A plain text editor (such as Notepad, TextEdit, VS Code, or Sublime Text) if you wish to view or modify the source code.

---

### Step 1: Save the Code
1. Copy the complete HTML code provided in the prerequisite output.
2. Open your plain text editor and paste the code into a new, blank document.
3. Save the file with the name **`index.html`** (ensure the file extension is `.html` and not `.txt`).

---

### Step 2: Open in a Web Browser
You do not need to set up a local web server, Node.js environment, or database to run this application. 

1. Locate the saved **`index.html`** file on your computer using your file explorer or finder.
2. **Double-click** the file, or **right-click** it and select **Open with**, then choose your preferred web browser (e.g., Chrome, Firefox, Edge, Safari).
3. The YouTube clone interface will load immediately.

---

### Step 3: Explore Interactive Features

Once the page is open in your browser, you can test the following built-in interactive features:

* **Toggle the Sidebar Navigation:**
  * Click the **Hamburger menu icon** (`☰`) located in the top-left corner of the header to collapse or expand the left sidebar. Notice how the main content area adjusts its left margin dynamically.

* **Filter Video Feeds by Category:**
  * Click any of the **category filter chips** (such as *All*, *Gaming*, *Programming*, *Music*, *Podcasts*, etc.) located just beneath the top navigation bar. The video grid will instantly filter to show only videos matching the selected category.

* **Open and Play Mock Videos:**
  * Click on any **video card** in the feed grid. This action opens an interactive video modal overlay complete with a responsive HTML5 video player, custom video title, channel information, engagement statistics, and action buttons.
  * To close the video player, click the **`X`** close button in the top-right corner of the modal, click anywhere on the dark background backdrop, or press the **`Esc`** key on your keyboard.
