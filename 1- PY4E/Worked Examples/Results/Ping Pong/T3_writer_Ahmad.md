# Python Pong Game: User Guide

Welcome to the classic **Pong Game** built using Python's built-in `turtle` graphics module! This guide will walk you through how to set up, run, and play the game with a friend.

---

## Prerequisites

Before running the script, ensure you have the following:
* **Python Installed:** Python 3.x must be installed on your system (the `turtle` module comes pre-installed with standard Python installations on Windows, macOS, and most Linux distributions).

---

## How to Run the Script

1. **Save the Code:** Copy the Python script provided and save it into a file named `pong.py`.
2. **Open Your Terminal or Command Prompt:** Navigate to the folder where you saved `pong.py`.
3. **Run the Game:** Execute the following command in your terminal:
   ```bash
   python pong.py
   ```
   *(Note: Depending on your system configuration, you may need to use `python3 pong.py` instead).*

4. **Exit the Game:** To close the game at any time, simply click the close button (`X`) on the game window.

---

## Player Controls

The game is designed for two players sharing the same keyboard. 

| Player | Paddle Location | Movement Keys | Action |
| :--- | :--- | :--- | :--- |
| **Player 1** | Left Paddle | **`W`** <br> **`S`** | Move Paddle Up <br> Move Paddle Down |
| **Player 2** | Right Paddle | **`Up Arrow`** <br> **`Down Arrow`** | Move Paddle Up <br> Move Paddle Down |

Enjoy the game and see who can reach the highest score!
